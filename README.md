# ATHELGARD 

**Athelgard** is a simple terminal based Role Play Game. You play as King Rover, a king who has forgotten his past and is now roaming in the beautiful yet dangerous realm of Athelgard. The Null a creature who is looking for his master is your new enemy!


**STILL IN DEVELOPMENT**

## 🌟 Highlights

- Lightweight 
- Simple Storyline 
- Text-based

## to run in terminal

Copy and paste the commands in your terminal

1. Install OpenJDK (use latest ver. replace 21 with latest ver.), git and gradle:

```bash
pkg install openjdk-21 git gradle -y
```

2. Clone this repository:
```bash
git clone https://github.com/rrrightrat/Athelgard.git
```
3. Open Athelgard directory:
```bash
cd Athelgard
```
4. Build/compile the code:
```bash
gradle build
```
5. Run:
```bash
gradle run
```
OR use this if gradle doesn't work:
```bash
java -cp build/classes/java/main com.codewithrat.Main
```
